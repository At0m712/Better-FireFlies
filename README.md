# Better FireFlies (BFF)

BFF is a client-side mod that add 3D FireFlies during night.

The FireFlies are purely decorative and they create their own dynamic light.

# Biome

+ Swamp
+ Forest
+ Jungle 
+ Lush Caves
+ ALL Caves (During night)

# Configuration

The dynamic light can cause lag, so if your computer can't handle it.
Use this command `/fireflylight` to turn on/off the dynamic light.


Feel free to add this to your modpacks
